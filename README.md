# HexRelic F-Droid repository

Apps by HexRelic, ready to install and update from any F-Droid client (F-Droid, Droid-ify,
Neo Store).

| App | What it does | Source |
|---|---|---|
| WitnessClip | Records audio and seals it so anyone can check it hasn't been edited | [HexRelic/WitnessClip](https://github.com/HexRelic/WitnessClip) |

## Add this repository

Repository address:

```
https://hexrelic.github.io/fdroid/repo
```

Fingerprint of the repository key (SHA-256):

```
BB1709DC3912D984DF24876838BCF2A168500F2072516125BA6C3BF942E1731E
```

<a href="repo/index.png"><img src="repo/index.png" width="200" alt="QR code to add the HexRelic repository"></a>

On your phone, scan the QR code with F-Droid (**Settings → Repositories → +**, then the QR
button) or Droid-ify, or open
[this link](https://fdroid.link/#https://hexrelic.github.io/fdroid/repo?fingerprint=BB1709DC3912D984DF24876838BCF2A168500F2072516125BA6C3BF942E1731E),
which adds the address and fingerprint in one step. You can also paste the address by hand;
the client checks the fingerprint the first time it connects.

## What is published here

Only the APKs released on each app's GitHub page, unmodified and signed by their developer. The
repository index is signed with a separate key. Every APK is checked against the app's own
signing certificate before it is listed, so an APK signed by anyone else is refused.
